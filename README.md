Bootloader and kernel buatan warga slowy belajar bareng livestream arfy slowy

## prerequites

- GCC
- NASM
- qemu
- roti khas lempuyangan

## Cara Menjalankan

```
// compile dan linking menjadi image
make 

// jalankan dengan menggunakan qemu
make run

// bersihin data hasil compile dan linking
make clean
```
